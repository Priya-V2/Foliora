# Dashboard Principles

Dashboard should answer:

- Is my portfolio live?
- What should I do next?
- What do recruiters see?
- How healthy is my portfolio?

Avoid analytics-heavy layouts.

Focus on portfolio management.

---

# Editor Principles

Never overwhelm users.

Edit one section at a time.

Autosave continuously.

Provide immediate feedback.

---

# Template Principles

Templates are a marketplace.

Users should be able to

- Browse
- Preview
- Purchase
- Apply

without leaving the page.

---

# Design Rules

DO

✓ Large whitespace

✓ Consistent spacing

✓ Soft shadows

✓ Rounded corners

✓ Simple layouts

✓ Strong hierarchy

✓ Clear CTA

✓ Reusable components

✓ Responsive design

✓ Professional typography

---

DON'T

✗ Multiple button styles

✗ Heavy gradients

✗ Glassmorphism everywhere

✗ Bright colors

✗ Random spacing

✗ Multiple accent colors

✗ Deep nested navigation

✗ Large forms

✗ Visual clutter

---

# Product Philosophy

Every interaction should reduce the time required to publish a professional portfolio.

The interface should feel effortless, predictable and polished.

Users should spend their time improving their portfolio—not learning the application.
